# The Pool paper

`paper.pdf` is *Pool: A Practical OT-based OPRF from Learning with Rounding* by
Alex Davidson, Amit Deo and Louis Tremblay Thibault, published as
[IACR ePrint 2025/1816](https://eprint.iacr.org/2025/1816). `paper.txt` is a
plain-text extraction of the same document, kept for searching and quoting.

Both files are here for reference. Copyright stays with the authors and their
publisher, and the [repository license](../../LICENSE) does not apply to them.
If you reference the paper, link to the ePrint entry rather than these files.
